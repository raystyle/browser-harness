# 原语：可观测（observability）

## 查询面

- `bh sessions`：实例清单 + 窗口/tab 全表 + 附着策略
- `bh doctor`：附着健康（browser attachable / daemon / CDP / 资产一致性）
- `bh dashboard`：只读网页看板（127.0.0.1:9870，SSE 每 2 秒）：工作实例 / 浏览器状态 / 后台任务 / 事件 / 日志消息

## 看板铁律

- **只读**：观察一切，不操作任何进程与浏览器（无 /quit 面）
- 事件用 **peek**（非破坏窥视 + seq 唯一键前端累加），日志浏览器侧累加、默认显示最新几条
- rmux 面板显示**原生命令行**（pid 跨代解析 cmd 包装壳 -> node 真身）

## 判读口径

- default 实例空闲退出 = **待命**（正常 lazy），具名实例 down = 监督故障（红）
- 页面判定七判中文化；状态 = 圆点 + 纯文本（原生惯用语），不用彩色胶囊
