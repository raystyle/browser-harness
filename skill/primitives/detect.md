# 原语：检测（detect）

页面异常先诊断，七判 + 事件流证据 + 处置建议一次出：

| 判定 | 含义 | 处置 |
| --- | --- | --- |
| challenge-stuck | 人机挑战脚本载入但调用超时（空白页） | 重载一次重跑挑战 |
| network-stalled | 核心请求超时 + 空白 | 查网络路径/代理 |
| blocked | 墙词或 403/429 簇 | 如实报不硬闯 |
| login-wall | 登录表单已渲染 | 用户登录，凭据越界 |
| blank | 无文本无失败签名 | 截图比对 |
| asset-throttled | 主域活、资源域 429/失败簇（出口 IP 限流） | 换出口或等窗口 |
| ok | 可交互 | 按需交互诊断 |

证据来源：daemon 事件环的**非破坏窥视**（peek，带 seq/time 戳、守护侧过滤），绝不清空（drain 会饿死依赖事件的触发器）。

## 命令

- `bh detect [url片段]`（无参 = 活动附着 tab；匹配不到如实报并列出已开 tab）
