| M001 | Node undici WebSocket 连接失败时 `ErrorEvent.message` 为空串，`?? fallback` 不触发，错误信息被吞 | 错误消息取值用 truthiness 判断而非 `??` 链 | 已机制化 [实证: 2026-09-04 移植期] |

| M004 | `Input.*` 事件发到从未激活过的 tab 会挂起（无报错无响应） | withInputRetry：先激活 target 再重发输入事件 | 已机制化 [实证: 2026-09-04] |

| M006 | Windows 上 `bh chrome start` 静默兜底到 Edge：三个连锁缺陷：(a) 硬编码路径列表盲区；(b) `--version` liveness 探测在 Windows 无语义（Chromium 不打印；日常实例在跑时探测挂起 ETIMEDOUT 误杀第一顺位 Chrome Dev；Edge 的「已在现有的浏览器会话中打开」输出+exit 0 反而误判为活）；(c) `agentChromePids` 按 `Name='chrome.exe'` 过滤导致 stop 杀不掉兜底 msedge | 已修复机制化：chromeBinary Windows 分支改注册表扫描（StartMenuInternet + App Paths）+ CDP 偏好排序，去掉 --version；pids 改纯命令行 marker 过滤；`bh chrome start` 输出明示浏览器身份 [实证: 2026-09-04 修复后 stop 杀掉 Edge、start 选中 Chrome Dev、/json/version 报 Chrome/154.0.8025.0] | 已机制化 |
| M007 | 锁的时间维抢占偷活锁：agent-chrome 锁默认 `stealAfterMs: 30s`，慢启动（Chrome 更新/冷盘）超 30s 时第二个进程偷走活人的锁并发双 spawn 打同一端口；task-port 锁自知 30s 不够改用 1h，两处标准不一。根因：无内核锁（fs4 类）时时间维抢占天然不安全，只有 pid 死亡判定可靠 | 已修复机制化（学习 nu_plugin_browse）：`stealAfterMs: Infinity` 只认 pid 死亡（agent-chrome 与 task-port 统一）；锁文件加 meta 字段；launchAgentChrome 锁内写归属记录 bh-agent.json（bin/port/pid），isAgentChromeRunning 从「ping 端口」升级为「端口活 + 归属一致 + UA 家族匹配」；stop 补第三级端口表强杀（netstat/lsof -> kill）[实证: 2026-09-04 并发双 start 端口表 LISTENING=1；Chrome 重启后 daemon 22s 自愈重附着] | 已机制化 |
| M008 | 页面常驻 SDK 的四个连环坑（google-search 标准化实测）：(a) `document.execCommand('insertText')` 对 React 受控输入无效（value 始终空，空表单提交停在首页）；(b) 单个 evaluate 内触发表单提交，导航销毁执行上下文（CdpError -32000 inspected target navigated）；(c) `Page.addScriptToEvaluateOnNewDocument` 每次导航重放注册时刻的 source 快照，且源码幂等 guard `if (__gs) return` 让旧版实例挡死新版（`__gs.results is not a function`）；(d) 导航过渡期 evaluate 返回 null 或抛错属正常瞬态。另：skills.ts PAYLOAD_EXT 白名单漏 `.js` 导致 SDK 产物不分发 | 已修复机制化：(a) goto_url 直达 `/search?q=` 不做 DOM 输入模拟；(b) 两段式（命令层导航，SDK 只在新文档提取）；(c) ensure_app_sdk 用源码指纹（djb2）做注册判重 + SDK guard 按版本跳过（改行为必须 bump V，G002 规则）；(d) 轮询容忍瞬时 null/异常，deadline 裁决；(e) PAYLOAD_EXT 补 `.js` [实证: 2026-09-04 两步契约全链路绿（指标 1478B/5 条），墙场景 challenged 如实报，tab 重建自愈] | 已机制化 |
