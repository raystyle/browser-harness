## 踩坑（当日连环）

- rmux 会话死但 pane 壳残留骗过 hasSession；杀进程须走会话级
- 插件入口直跑无人调 main：自执行守卫须按 process.argv[1] 判定；角色派发后不可 return（会触发 process.exit 杀常驻循环）
- runPlugin 无条件 ensureDaemon(default) + 马标记优先 = default 抢应用 tab：selfManaged 声明 + 空白优先双修
- 模板字面量里的正则反斜杠被吃（页面脚本语法错误）;多行模板里 TS 注解泄漏
- worker 触发器 drain_events 清空事件环饿死看板 peek：触发只探测不清空
- repl 多语句片段不自动 return（静默空输出 exit 0）；模板内嵌 \n/三反引号被外层先解释 + js() 吞页内异常 = 「空输出」三重假象（M009/M010，全天最大时间黑洞）
- CF 对页内连续 format=json fetch tarpit（首 2 次 200 后挂起）；Medium 过墙后搜索会话限流而文章页正常（M011/M012）
