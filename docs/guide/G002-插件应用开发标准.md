# G002：插件应用开发标准

> bh 插件应用（assets/apps/*.mjs）的开发标准与禁令。方法细节见 R002；本件是强制项与验收门禁。依据：nu_plugin_browse skills 生态方法评估（2026-09-04，diary 有记）。

## 适用范围

新建站点应用（搜索/抓取/监控类）一律执行本标准。现有应用按「迁移分级」表处理，不作一刀切重写。

## 强制项（新应用）

1. **固定形合约**：所有命令输出 JSON，顶层必含 `_ok: boolean`、`_v: string`（合约版本）、`_ts: string`（ISO 时间戳）；失败路径 `{_ok: false, error: '<分类前缀>: <detail>'}`，**禁止**用 null/空数组/退出码表达失败
2. **版本合约**：SDK 常量 `CONTRACT_VERSION` 与命令层 `_v` 必须同源（一处定义，注入时携带）；改返回形状必须 bump
3. **两步契约**：集合数据预计 >10KB 时落盘 `<workspace>/cache/<app>/<cache>.json`（batch 追加、留最近 100、tmp+rename 原子写），第一步只返指标 `{_ok, count, shape{item, item_types}, bytes, cache, batch_id}`；小返回（单条/状态）直接返回
4. **会话生命周期**：命令入口先 ensure（app tab 存在 + SDK 探活带超时 -> 复用；探活失败 -> 重开 tab 重注入）；注入完成不等于可用，探活通过才算 open
5. **错误分类前缀**：`AUTHORIZATION:`（不可恢复）/ `RATE_LIMITED:`（附 reset）/ `LOCKED:`（人工）/ `CAPTCHA|WALL:`（**停止，提示用户窗口内人工处理，禁止自动重试**）/ `NOT_FOUND:` / `NETWORK:` / `TIMEOUT:`；决策树登记进 SKILL 面
6. **一个 main 一个业务动作**：插件入口一次 evaluate 只执行一个站点动作（防 CDP 并发冻结）；参数序列化恰好一次

## 禁令

- 禁止内联 JS 探针返回可能超 ~10KB 的集合（截断与冻结之源）
- 禁止无就绪判官的 DOM 探针（「查了但没等」是假数据之源，M004 同源教训）
- 禁止把墙/验证码当空结果静默返回
- 禁止插件自带第二套浏览器生命周期管理（一律走 daemon 的 ensure_app_tab / agent Chrome）
- 禁止 SDK 产物引入 runtime 依赖（构建期 esbuild 为 devDependency，产物必须自包含 IIFE）

## 结构与命名标准

```text
assets/sdk/<app>.ts        SDK 源码（TS，导出 __<app> 全局的 iife 入口）
assets/sdk/<app>.min.js    构建产物（进 git；npm run build:sdk 统一构建）
assets/apps/<app>.mjs      命令层薄封装（ensure -> 调 __<app> -> check -> stash/pluck）
<workspace>/cache/<app>/   两步契约缓存（.json，gitignore，运行时生成）
```

## SDK 注入基建（已落地）

`ensure_app_sdk(app, url, sdkSource)`（browser_helpers）：ensure_app_tab -> 按源码指纹判重 -> `Page.addScriptToEvaluateOnNewDocument` 注册（导航自动重放）+ 当前文档立即注入 -> 页面内存指纹标记。SDK 侧 guard 按版本跳过（改行为必须 bump V）。实测注意（M008）：导航过渡期 evaluate 的 null/异常是正常瞬态，命令层轮询容忍、deadline 裁决；跨导航操作拆两段，不在单个 evaluate 内触发表单提交。

## 验收门禁（新应用 merge 前）

- [ ] 固定形合约全覆盖（含失败路径）
- [ ] 集合输出走两步契约，指标恒 <1KB
- [ ] 墙/CAPTCHA 场景实测：如实报告且不自动重试
- [ ] 断连场景实测：tab 重开 + SDK 重注入后自愈
- [ ] 大结果不 inline（pluck 取数验证）
- [ ] SKILL 面登记：命令表 / cache 名 / 错误决策树 / 版本合约

## 迁移分级（现有应用）

| 应用 | 处置 | 理由 |
| --- | --- | --- |
| web-fetch、cookies | 保持 | 已符合侧车/直调模式，无痛点 |
| x-monitor / x-supervisor / x-worker | 保持 | 自治应用，已有自身文件状态与分片纪律 |
| bing-search | 升级（痛点驱动） | title 偶发空（M004 同源）-> SDK 常驻 + 就绪判官 |
| google-search | 升级（痛点驱动） | 内联全量结果 -> 两步契约 |
| x-search / x-harvest | 观望 | 已有文件产出，精神近似两步契约；触发痛点再迁 |

升级触发判据（写入 diary 即生效）：内联探针偶发空结果、返回可能超 10KB、需要跨调用状态三者居其一。
